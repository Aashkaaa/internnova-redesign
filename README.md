# InternNova Homepage Redesign

A concept redesign of the InternNova homepage, built as a mandatory task of the InternNova web development internship. It uses the existing website only as a reference for brand and content.

**Live site:** https://aashkaaa.github.io/internnova-redesign/
**Repository:** https://github.com/Aashkaaa/internnova-redesign

## What I improved

- Replaced the oversized hero title with a clear headline, two calls to action and animated stats
- Added a "How it works" section and a working FAQ, which the original homepage lacked
- Merged three stacked program rows into one tabbed Programs section (Basic, Pro, Courses)
- Improved text contrast on dark backgrounds and added a light/dark theme toggle
- Added scroll animations, a testimonial slider and a sticky glass navbar

## Features

- Fully responsive (desktop, tablet, mobile) with a mobile menu
- Tabbed programs rendered with JavaScript
- Testimonial slider with autoplay and controls
- Accessible FAQ accordion with keyboard support and ARIA states
- Newsletter form with email validation
- Respects reduced-motion preferences

## Tech stack

HTML5, CSS3 (Grid, Flexbox, custom properties, media queries), vanilla JavaScript, Git and GitHub Pages.

## Run locally

1. Clone the repository: `git clone https://github.com/Aashkaaa/internnova-redesign.git`
2. Open `index.html` in your browser.
